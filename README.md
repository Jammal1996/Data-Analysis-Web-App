1️⃣ Download the Project
Download the ZIP file and extract it form this link:

https://github.com/Jammal1996/Data-Analysis-Web-App

Or clone the repository:

git clone YOUR_REPOSITORY_LINK
Then open the project folder:

cd data_genius_app

2️⃣ Create Virtual Environment (Recommended)
Windows
python -m venv venv
venv\Scripts\activate
Mac/Linux
python3 -m venv venv
source venv/bin/activate

3️⃣ Install Required Libraries
Install all dependencies using:

pip install -r requirements.txt
If requirements.txt does not exist:

pip install flask pandas numpy matplotlib seaborn openpyxl

4️⃣ Run the Flask Application
Start the API server using:

python app.py
If successful, you should see something similar to:

Running on http://127.0.0.1:5000

5️⃣ Open the Website
Open your browser and go to:

http://127.0.0.1:5000
You should now see the Data Genius dashboard running locally 🎉


📂 Supported Features
✅ CSV / Excel / JSON Upload ✅ AI Data Analysis ✅ Automatic Charts ✅ Dataset Preview ✅ Smart Insights ✅ Data Cleaning ✅ Interactive Dashboard ✅ Flask REST API
